# Todo App

![Todo App Preview](preview.jpg)

A responsive Todo application built as part of the **Frontend Mentor Todo App Challenge**.

This project was created to practice JavaScript DOM manipulation, state management, Tailwind CSS, and browser localStorage.

## 🚀 Live Demo

(https://frontend-mentor-todolist-challenge.vercel.app/)
## 📌 Features

Users can:

* ✅ View a responsive layout on different screen sizes
* ✅ Add new todo items
* ✅ Mark todos as completed
* ✅ Delete individual todos
* ✅ Filter todos by:

  * All
  * Active
  * Completed
* ✅ Clear completed todos
* ✅ Toggle between light and dark themes
* ✅ Save todos and theme preference using localStorage
* ✅ Experience interactive hover states

## 🛠️ Built With

* HTML5
* Tailwind CSS
* JavaScript (ES6+)
* Local Storage API
* Responsive Design

## ⚙️ How to Run Locally

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Navigate to the project folder:

```bash
cd todo-app
```

3. Open `index.html` in your browser.

Or use the VS Code Live Server extension.
